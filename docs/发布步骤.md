# 发布到 GitHub 的步骤（第一次也能走完）

目标：把代码传上去，再挂一个 Release 让别人下载 exe。

已经给你准备好的目录：`github-repo/`（2 MB，25 个文件）。
**直接用它当仓库根目录**，里面没有你的存档、没有依赖包、没有构建垃圾。

---

## 0. 先确认这三件事

1. `github-repo/` 里**没有** `samples/`、`vendor/`、`*.sav` —— 有的话删掉，别传自己的存档（里面有你的 SteamID）。
2. 想好仓库名，例如 `pbz-save-editor`。
3. 仓库选 **Public**（私有仓库别人下不到 exe）。

---

## 1. 装工具（二选一）

**推荐：GitHub Desktop**（图形界面，不用记命令）

```
winget install --id GitHub.GitHubDesktop -e
```

**或者：Git 命令行**

```
winget install --id Git.Git -e
```

装完可能要重开一次终端。

---

## 2. 建仓库

### 用 GitHub Desktop

1. 打开 GitHub Desktop，登录你的 GitHub 账号（没有就先去 github.com 注册）。
2. 菜单 `File → New repository…`
3. 填：
   - **Name**：`pbz-save-editor`
   - **Description**：`影之刃零 存档修改器 · 货币/物品/任务可视化编辑`
   - **Local path**：随便一个空目录，比如 `D:\code`
   - **Initialize with README**：**不勾**（我们自带 README）
   - **Git ignore**：**None**（自带 .gitignore）
   - **License**：**None**（自带 LICENSE）
4. 点 `Create repository`。
5. 点右上角 `Publish repository`：
   - 取消勾选 `Keep this code private`
   - 点 `Publish`

### 用命令行

在 github.com 上点 `+ → New repository`，名字 `pbz-save-editor`，**不要**勾选自动生成 README / .gitignore / license，创建后照抄它给的命令：

```
cd github-repo
git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/<你的用户名>/pbz-save-editor.git
git push -u origin main
```

---

## 3. 把文件放进去

1. 打开 `github-repo/`，**全选里面的内容**（不是文件夹本身）。
2. 复制到仓库目录（GitHub Desktop 第 3 步里选的那个 `Local path`）。
3. 回到 GitHub Desktop：
   - 左下 `Summary` 写 `初始发布：存档修改器 v1.0.0`
   - 点 `Commit to main`
   - 点 `Push origin`

命令行则是：

```
git add .
git commit -m "初始发布：存档修改器 v1.0.0"
git push
```

刷新网页，应该能看到 README 和截图。

---

## 4. 发 Release（让别人直接下载 exe）

1. 仓库页右侧点 `Releases → Create a new release`
2. **Choose a tag**：输入 `v1.0.0`，点 `Create new tag on publish`
3. **Release title**：`v1.0.0 · 影之刃零 存档修改器`
4. **描述**（可直接改）：

```
首个版本。

- 自动读取货币 / 天数 / 杀意 / 暗源 / 物品 / 任务
- 物品与饰品带中文名，支持改数量、等级
- 未完成页可一键补发未获得的饰品
- 任务分支状态、进度可改
- 写回前自动备份，Oodle 存储块写回

Windows 10/11 x64。单文件版直接双击；文件夹版解压后运行。
如果 SmartScreen 提示，右键压缩包/程序 → 属性 → 勾选「解除锁定」。
```

5. **Attach binaries**：把这两个拖进去
   - `PBZSaveTool.exe`
   - `PBZSaveTool-folder.zip`
6. 点 `Publish release`

---

## 5. 之后更新

1. 改完代码，替换仓库里的文件
2. GitHub Desktop 里 `Commit` → `Push`
3. `Releases → Draft a new release`，tag 写 `v1.0.1`，重新上传两个文件

---

## 常见问题

**能不能直接把 exe 提交进仓库？**
不建议。仓库只放源码，exe 走 Release 附件（不占 git 历史，下载也快）。`.gitignore` 已经排除了 `dist*/`。

**需要哪些文件在仓库里？**
`github-repo/` 里的 25 个文件就是完整可运行的源码 + 中文名表 + 解码器 DLL。

**别人没有 Python 能跑吗？**
能，用 Release 里的 exe。

**发布前最好补一句免责声明**（README 底部已经有了思路）：
单机存档工具、与开发商无关、使用风险自负、不要用于联机。

**法律上注意**
- `names.json` 是从游戏资源导出的物品名，属于游戏内容；介意的话可以不传，程序会自动回退显示内部 ID。
- 存档 AES 密钥写死在 `pbz_editor.py` 里，这类工具社区很常见，但严格说涉及绕过保护，自己评估。
- 不要在仓库里放游戏本体文件、你的存档、或第三方修改器的二进制。
